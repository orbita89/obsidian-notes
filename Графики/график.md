// ====== НАСТРОЙ И ЭНЕРГИЯ — ПЕРЕКЛЮЧАЕМЫЙ ГРАФИК ======
const MODE = "week"; // "week" или "month"

const notes = dv.pages('"Ежедневник"')
    .where(p => p.дата && p.настрой != null && p.энергия != null)
    .sort(p => p.дата, 'asc');

if (!notes.length) {
    dv.paragraph("Нет данных для графика");
} else {

    const groups = new Map();

    for (let n of notes) {
        const dt = dv.luxon.DateTime.fromISO(n.дата);
        const key = MODE === "week"
            ? `${dt.weekYear}-W${String(dt.weekNumber).padStart(2,'0')}`
            : dt.toFormat("yyyy-MM");

        if (!groups.has(key)) groups.set(key, []);
        groups.get(key).push({
            mood: Number(n.настрой),
            energy: Number(n.энергия)
        });
    }

    const labels = [];
    const mood = [];
    const energy = [];

    for (let [k, arr] of groups.entries()) {
        labels.push(k);
        mood.push(arr.reduce((a,e)=>a+e.mood,0)/arr.length);
        energy.push(arr.reduce((a,e)=>a+e.energy,0)/arr.length);
    }

    dv.el("div", `
\`\`\`chart
type: line
labels: ["${labels.join('","')}"]
series:
  - name: Настрой
    data: [${mood.map(v=>v.toFixed(2)).join(',')}]
  - name: Энергия
    data: [${energy.map(v=>v.toFixed(2)).join(',')}]
options:
  title: "Динамика состояния (${MODE === "week" ? "по неделям" : "по месяцам"})"
  legend: true
  yAxis:
    min: 0
    max: 10
\`\`\`
`, { cls: "markdown" });

}

### 🔹 Что делает этот ГРАФИК:

1. Берёт все записи из `Ежедневник`.
    
2. Вычисляет **номер недели в году** для каждой даты.
    
3. Группирует `настрой` и `энергию` по неделям и берёт **среднее значение** за неделю.
    
4. Строит график, где по оси X — недели, по Y — баллы от 0 до 10.
