ALTER TABLE  используеться CHANGE COLUMN. Переименование колонки и одновременное изменение её описания.CHANGE - когда нужно поминять тип данных. в случиях когда просто нужно поминять названия лучше использовать RENAME
Проверка:
`NOT EXISTS` — это условие в SQL, которое проверяет **отсутствие строк в подзапросе**. Оно возвращает `TRUE`, если подзапрос **не находит ни одной записи**, и `FALSE`, если хотя бы одна строка найдена. Это один из самых надёжных способов проверить, что связанных данных **не существует**.
